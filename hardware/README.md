# JJY 送信 HAT(Raspberry Pi 4 用・40kHz / 60kHz ソフト切替)

GPIO の 2 本だけで、JJY 仕様の振幅変調(最大 100% / 低レベル 10%)した 60kHz(はがね山・既定)または 40kHz(おおたかどや山)を
小型フェライトバーアンテナに出す基板です。

| GPIO | ピン | 役割 |
|------|------|------|
| GPIO18 (PWM0) | 12 | キャリア 60kHz(50%デューティ矩形波) |
| GPIO23 | 16 | 振幅切替。Low = 最大、High = 約 10% |
| GPIO26 | 37 | 帯域切替。Low = 60kHz、High = 40kHz |
| 3V3 / GND | 1 / 6 | 電源 |

## 回路

```
 3V3 ── R5 1k ── LED1 ──┐
                        │
 GPIO23 (pin16) ────────┴─── U1B /OE (4)      (R3 10k で 3V3 へプルアップ)
 GPIO18 (pin12) ──┬──────── U1A in (2), U1B in (5)  (R4 10k で GND へプルダウン)
                  │
        U1A /OE(1)=GND          U1B 出力(6)
        U1A 出力(3)                │
            │                      │
           R1 1k                  R2 100Ω
            └──────────┬───────────┘
                       │  駆動ノード
                    C2〜C5 (共振コンデンサ 並列, 計 7.05nF)
                       │
                    L1 フェライトバーアンテナ (約1mH) ※J2で基板外へ
                       │
                      GND

 U1: VCC(14)=3V3 (C1 100nF をピン近くに), GND(7)=GND。未使用ゲートC,Dの入力は GND。
```

- **U1A**(/OE を GND に固定 = 常時有効)が 1kΩ 経由で常にキャリアを出す → 低レベル。
- **U1B**(GPIO23 = Low で有効)が 100Ω 経由で加わる → 並列で約 91Ω。
- コイル直流抵抗を約 10Ω とすると電流比は (1000+10)/(91+10) ≈ 10 倍 = **-20dB(10%)**。
- D1 は GPIO23 が Low の間(=最大振幅の間)だけ点灯。秒ごとの点滅で動作確認できる。
- U1B 無効時は出力がハイインピーダンス(R2 側は浮く)になるだけで、低レベルは U1A のみで生成される。

## 共振コンデンサ(直列共振 f = 1/(2π√LC))

L1 = 1mH の場合:

| 部品 | 値 | 備考 |
|------|----|------|
| C2 | 4.7nF C0G | |
| C3 | 2.2nF C0G | |
| C4 | 150pF C0G | |
| C5 | 未実装(DNP) | 60kHz 側の微調整用パッド。数十 pF を追加 |
| C7 / C8 / C9 | 4.7nF / 2.2nF / 2.2nF C0G | 40kHz 用に追加する 9.1nF(K1 経由) |

40kHz のときは K1 が C7〜C9 を並列に加え、合計 16.15nF で約 39.6kHz になります。

合計 7.05nF で f = 59.9kHz。40kHz / 60kHz の切替はソフトで行う(下の「帯域切替」)。

実際のコイルの L は個体差が大きいので、**LCR メータで L を測って C を計算**し、
オシロで駆動ノードの電流(R1 の電圧降下)が最大になる C に追い込んでください。
(他のコイルを使う場合: C = 1 / ((2πf)² · L))

## 出力を弱くする(重要)

日本の電波法では、**微弱無線局**(322MHz 以下では 3m で 500µV/m 以下)の範囲なら免許不要ですが、
これを超える出力は違法になり得ます。次の方針で、時計に数 cm〜数十 cm まで近づけたときだけ受かる程度にしてください。

- R1/R2 を 10 倍(10kΩ / 1kΩ)にして出力を落とす。比率(10:1)は維持される。
- アンテナを時計のすぐ近くに置く。基板から離して配線する。
- 電界強度は測定器(または校正済みの受信機)で確認する。

## 調整手順

1. `sudo systemctl stop jjyd` のあと、`--dry-run` でなく実機で `sudo python3 -m jjyd` を起動。
2. オシロで GPIO18 が 60kHz であること、GPIO23 が 1 秒周期で Low パルスになること(0.2 / 0.5 / 0.8 秒)を確認。
3. 駆動ノードで 1 秒ごとに振幅が約 10:1 に変わることを確認。
4. 共振コンデンサを調整してアンテナ電流を最大化。
5. 電波時計を近づけ、強制受信(多くは 手動で受信ボタン)を試す。
   受信には約 2〜3 分(連続 2 フレーム確認)必要。

## 帯域切替(40kHz / 60kHz)

直列共振の同調コンデンサを、GPIO26 でフォトモスリレー K1(AQY212SX)を使って切り替えます。

- GPIO26 = Low(既定・起動直後): 60kHz 用の 7.05nF のみ。
- GPIO26 = High: K1 が閉じて C7〜C9(9.1nF)を並列に追加、合計約 16.15nF で 40kHz。
- ソフト: `/etc/jjyd.toml` の `khz`(40 / 60)と `select_gpio = 26`。jjyd が起動時にキャリア周波数と GPIO26 を設定する。変更後は `sudo systemctl restart jjyd`。
- フォトモスリレーを選んだ理由: 共振コンデンサの両端は GND から浮いていて電圧が約 ±5V 振れる。普通のトランジスタだと逆向きの電圧で導通してしまうが、絶縁されたフォトモスなら問題ない。
- オン抵抗は 1Ω 弱。コンデンサの回路に直列に入るだけで、影響は小さい。
- 注意: 実際の同調は使うコイルの L で変わるので、**各周波数で電流を測って調整**すること(60kHz は C5、40kHz は C7〜C9 の組合せで)。
- 未確認: K1 のピン配置(1=LED+, 2=LED−, 3/4=負荷)と LED 動作電流(3mA 以下のはず)はデータシートで未確認。発注前に確認すること。

## RTC(基板上に実装)

DS3231SN(U2)と CR2032 ホルダ(BT1)を基板に載せてあり、再起動直後でも NTP 同期を待たずに送信を再開できます。

- 配線: SDA = GPIO2(pin3)、SCL = GPIO3(pin5)、VCC = 3V3、VBAT = BT1 の +。I2C のプルアップは Raspberry Pi 側(1.8kΩ)を使うので基板には載せていない。
- U2 は 32kHz / INT / RST を未接続にしている(必要になったら配線を追加)。
- C6 100nF が U2 のバイパス。
- BT1 は CR2032 用の MYOUNG BS-07-A1BJ001(LCSC C2979167、スルーホール)で、**手はんだ**。JLCPCB では実装しない。
  **極性(パッド 1 = +)を確認すること。** KiCad 標準フットプリントのシルクにも「+」がパッド 1 側に描かれているが、発注前にホルダのデータシートでも確認する。
- 電池は 1 次電池(CR2032)。DS3231 のバックアップ電流は数 µA 程度で、年単位で持つ。
- ソフト: `sudo ./scripts/install.sh` が `dtoverlay=i2c-rtc,ds3231` を有効化し、`/etc/jjyd.toml` の `[rtc] enabled = true` にする(既定)。RTC 未実装の基板なら `JJY_RTC=0` を付けて実行。
  前回同期から 24 時間以内なら、再起動直後に NTP 未同期でも送信を許可する。
- 未確認: Raspberry Pi 実機での RTC 動作(オーバーレイ・udev の手順は Raspberry Pi OS Bookworm の一般的な手順に沿ったもので、実機では未検証)。

## KiCad データ

[kicad/](kicad) に KiCad 8 以降で開けるプロジェクト(`jjy-hat.kicad_pro`)があります。
基板は 65×56mm(Raspberry Pi HAT の外形・取り付け穴位置)、2 層、部品はすべて表面、裏面は GND ベタです。
プレビュー: [jjy-hat-pcb-preview.png](kicad/jjy-hat-pcb-preview.png)

- データは [kicad/gen_kicad.py](kicad/gen_kicad.py) で生成しています。部品値や配置を変えるときはこのスクリプトを直して `python -I gen_kicad.py` で再生成します。
- フットプリントは KiCad 標準ライブラリの実物、シンボルも標準ライブラリ(Device・Connector_Generic・power・Mechanical)の実物を使い、自作の 3 点(74LVC125・DS3231SN・AQY212S)はプロジェクト内のライブラリ [JJY.kicad_sym](kicad/JJY.kicad_sym) にまとめています(`sym-lib-table` で登録済み)。
- 生成時に自前の簡易チェック(クリアランス 0.2mm・ネット連結)を行い、さらに KiCad 10.0.7 の ERC/DRC を実行して、**ERC 0 件・DRC 0 件(警告を含む)・未配線 0・回路図と基板の不一致 0**を確認済みです。
- 取り付け穴(H1〜H4)も回路図に入れてあり、BOM・部品位置からは除外されます。
- 部品番号は印刷(シルク)ではなく Fab 層に置いています(パッドとの重なりを避けるため)。
- 初回に開いたら、基板エディタで `B` キー(ゾーン再充填)を押して GND ベタを塗り直してください。
- 未確認: 実際の製造(ガーバー出力・基板メーカー DRC)、アンテナ電流、実機動作。
