# JJY 送信ユニット(Raspberry Pi 4 用・40kHz / 60kHz ソフト切替)

Raspberry Pi の GPIO に**ケーブルでつなぐ**別基板です(Rev C)。次をすべて 1 枚に載せています。

- JJY 仕様の振幅変調(最大 100% / 低レベル 10%)をした 60kHz(はがね山・既定)/ 40kHz(おおたかどや山)の送信回路
- **アンテナ**: 基板上のスパイラルコイル(部品なし)と、外付けアンテナ用の端子(J2)の **2 択**(ジャンパ JP1 で選ぶ)
- 現在時刻を表示する LCD(16×2、I2C)と、送信信号を示す LED
- RTC(DS3231 + CR2032)

金属ケース(GPIO が細いスリットから見えるタイプ)の中の Pi にも使えるよう、Pi に挿す HAT ではなく、**ケースの外に置く基板**にしてあります(100×96mm)。
**J1 は基板の上辺の中央**にあり、ケーブルは上へ出ます。その下に送信回路と RTC、右下にコイル、左下に LCD の取り付け位置(J3)があります。

## Pi との接続(J1)

J1 は **2×20 の 2.54mm ピンヘッダ**(Pi の GPIO ヘッダと同じ並び・同じピン番号)です。2 通りの接続ができます。

- **40 ピンのフラットケーブル(1 対 1)**: Pi 側にメスのソケット、基板側に 2×20 の IDC ソケット。ピン 1 の印(赤線)を合わせる。
- **ジャンパ線(Dupont)**: 必要なピンだけを 1 本ずつつなぐ。

使うピン(Pi の物理ピン番号):

| 用途 | Pi のピン | 信号 |
|---|---|---|
| 電源 | 1 または 17 | 3V3 |
| GND | 6 / 9 / 14 など(どれか 1 本以上) | GND |
| I2C(LCD・RTC) | 3 / 5 | SDA(GPIO2)/ SCL(GPIO3) |
| キャリア | 12 | GPIO18(PWM0) |
| 振幅切替 | 16 | GPIO23 |
| 送信信号 LED | 18 | GPIO24 |

- **ケースへの配線**: ケースの蓋にピンの名前が印刷されているので、見ながらつなげる。スリットの寸法・深さは**実物で確認**すること(ソケットが入らない場合は、ジャンパ線を使う)。
- 基板側の J1 は、使う信号だけジャンパ線でつなげば、40 ピンすべてを配線する必要はない。

## 回路

```
 GPIO18 ──┬──────── U1A in (2), U1B in (5)  (R4 10k で GND へプルダウン)
 GPIO23 ──┴─── U1B /OE (4) ─── R3 10k で 3V3 へプルアップ、D1 のカソードへ
                                   3V3 ── R5 1k ── D1(赤 LED)
 U1A(/OE=GND, 常時有効)出力 ── R1 10k ──┐
                                           ├── 駆動ノード ── JP1 ─┬─(2-3)─ L1(基板コイル)── GND
                                           │                      └─(1-2)─ J2(外付けアンテナ)── GND
 U1B(GPIO23=Low で有効)出力 ── R2 1.1k ──┘

 GPIO24 ── R7 330 ── D2(緑 LED)── GND      送信信号 LED
 3V3 ── R8 470 ── D3(黄 LED)── GND          通電表示(パイロットランプ。常時点灯)
 U1: VCC(14)=3V3 (C1 100nF)、GND(7)。未使用ゲート(C, D)の入力は GND。
```

- **U1A** は常にキャリアを出す(R1 経由 = 低レベル)。**U1B** は GPIO23 が Low の間だけ加わる(R2 が並列 = 高レベル)。
- 高レベルと低レベルの電流比は、駆動抵抗がコイルより十分大きいので **1 + R1/R2**(= 約 10.1 倍、-20dB、約 10%)。
- D1(赤)は高レベル(最大振幅)の間だけ点灯する(0.2 / 0.5 / 0.8 秒)。

## アンテナの選択(JP1)と外付けアンテナ(J2)

駆動信号は JP1 の中央のピン(2)に来ています。**短絡ピン(ジャンパ)をどちらに挿すかで、アンテナを選びます**(選ばれなかった側は開放になり、電波は出ません)。

| JP1 の短絡 | 使うアンテナ |
|---|---|
| 1-2 | 外付けアンテナ(J2 に接続) |
| 2-3 | 基板コイル(L1)← 標準 |
| なし | どちらにも出力しない |

### 外付けアンテナを使うとき(重要: R1/R2 を交換する)
- 外付けのフェライトバーなどは、基板のコイルよりずっと強い磁界が出ます(巻数 × 断面積 × 棒の透磁率が大きいため)。**基板コイル用の R1/R2(10kΩ / 1.1kΩ、電流 約 2mA)のままつなぐと、微弱無線局の限度を超えるおそれがあります。**
- そこで、外付けアンテナに替えるときは、**R1 と R2 をもっと大きな値に交換**して電流を減らします(リード部品なので交換は容易)。比は R1 = 約 9 × R2 を保ちます。
- 目安(フェライトバー: 直径 10mm × 長さ 100mm、100 回巻きの場合。**概算なので必ず実測で確認**):

| R1 / R2 | 電流(基本波のピーク) | 備考 |
|---|---|---|
| 220kΩ / 24kΩ | 約 0.1mA | 最初はこの値から。受からなければ下げる |
| 100kΩ / 11kΩ | 約 0.2mA | |
| 68kΩ / 7.5kΩ | 約 0.3mA | 概算で限度に近づく。実測が必須 |

- 巻数が少ない小さなコイルなら、基板コイル用の値(10kΩ / 1.1kΩ)のままでも使えます。目安は「巻数 × 面積 × 電流」が基板コイル(30 回 × 約 3cm² × 2mA)と同程度までです。
- 基板コイルに戻すときは、R1/R2 を 10kΩ / 1.1kΩ に戻し、JP1 を 2-3 にします。
- J2 のコイルには直流が流れません(駆動は交流のみ)。インダクタンスは 0.1〜3mH 程度で、厳密でなくて構いません(共振させていないため)。

## 共振オプション(外付けアンテナ用・通常は未実装)

外付けアンテナ(J2)側には、以前の設計と同じ**直列共振回路と、40kHz / 60kHz をソフトで切り替えるフォトモスリレー K1**の部品を置く場所を用意してあります(**未実装 = 基板に部品を載せない**状態が標準)。基板コイル(L1)側には影響しません。

構成(JP1 を 1-2 にしたとき): `JP1.1 → [共振コンデンサ] → J2.1(外付けアンテナ)→ GND`

| 記号 | 部品 | 役割 |
|---|---|---|
| JP2 | 1×2 ピンヘッダ + 短絡ピン | 短絡 = 共振回路をバイパス(標準)/ 短絡なし = 共振コンデンサを通す |
| C2・C3・C4 | 4.7nF・2.2nF・150pF(C0G、50V、±5%) | 60kHz 用(合計 7.05nF、1mH のコイルで約 59.9kHz) |
| C5 | 数 pF〜数十 pF | 60kHz の微調整用 |
| C7・C8・C9 | 4.7nF・2.2nF・2.2nF(C0G、50V、±5%) | 40kHz 用に K1 経由で追加(合計 16.15nF で約 39.6kHz) |
| K1 | AQY212SX(フォトモスリレー、SOP-4、LCSC C719754) | GPIO21(J1 の 40 番ピン)で 40kHz 用の C7〜C9 を接続 |
| R6 | 330Ω 1/4W | K1 の LED の電流制限 |

### 実装する手順
1. JP2 の短絡ピンを外す。
2. C2・C3・C4(と必要なら C5)を実装する。1mH 前後の外付けコイルなら、60kHz で共振する。
3. 40kHz も使うなら、K1・R6・C7〜C9 も実装する。
4. `/etc/jjyd.toml` の `select_gpio = 21` の行を有効にして、`sudo systemctl restart jjyd`。40kHz のときだけ GPIO21 が High になり、K1 が C7〜C9 を追加する。
5. 同調は使うコイルの L で変わるので、**各周波数でアンテナ電流を測って調整**する(C = 1 / ((2πf)² · L))。

### 注意(重要)
- 共振させると電流が増えます。共振の効果は、駆動抵抗(R1/R2 の並列)がコイルのリアクタンス(1mH・60kHz で約 380Ω)と同程度以下のときに出ます。標準の R1/R2(10kΩ / 1.1kΩ)では、共振させても電流はほとんど変わりません。
- 共振で電流を増やすために R1/R2 を小さくすると、**微弱無線局の限度を超えやすくなります**。外付けコイルの巻数を減らす、電流を測る、など実測で確認してください。
- K1 は SMD 部品です(JLCPCB で実装することもできますが、標準では DNP =未実装として出力しています)。ピン配置(1=LED+、2=LED−、3/4=負荷)と LED 電流はデータシートで未確認です。
- 未確認: この共振オプションは、実機で試していません。

## アンテナ(基板上のスパイラルコイル L1)

基板の右下に、外形 26mm 角の**四角いスパイラルコイル**を両面に作っています(表面は外側から内側へ、中心の穴で裏面へ移り、裏面は内側から外側へ)。

| 項目 | 値(生成スクリプトの計算 / 概算) |
|---|---|
| 巻数 | 約 15 回/面、合計約 30 回 |
| 配線長 | 約 2m(幅 0.25mm、ピッチ 0.6mm) |
| 直流抵抗 | 約 4Ω |
| インダクタンス | 約 15µH(概算。実測すること) |

- **共振はさせません**。駆動抵抗(約 1kΩ)がコイルのリアクタンス(60kHz で約 6Ω)よりはるかに大きいので、電流は抵抗だけで決まります。そのため、従来の共振コンデンサと帯域切替のスイッチ(K1)は**廃止**しました。40kHz / 60kHz の切替は**ソフトの `khz` の設定だけ**です。
- **銅ベタ禁止**: コイルの範囲は、表裏とも GND の銅ベタを抜いてあります(コイルの下に銅があると、渦電流で磁界が弱くなります)。
- **金属を近づけない**: コイルの近く(特に上や下)に金属板を置かないでください。
- 高レベルのアンテナ電流は約 2mA(2.1V ÷ R1・R2 の並列 約 1kΩ)。コイルが小さい分、電流を大きくして磁界の強さを保っている。

### 電界強度の概算(重要・実測で必ず確認)
上のコイルを、巻数 30、平均面積 2.9×10⁻⁴ m²、電流 2mA の磁気双極子として概算した値です。**概算は数十 dB の誤差があり得ます。**

| 距離 | 電界強度の目安 | 備考 |
|---|---|---|
| 3m | 約 40µV/m | 微弱無線局の限度(3m で 500µV/m)に対して約 20dB の余裕 |
| 1m | 約 1mV/m | |
| 0.3m | 約 40mV/m | 時計に近づける距離 |

- 時計は、基板のコイルの上や横に、**数 cm〜30cm** まで近づけて使います。
- 受信できないときは、(1) 近づける、(2) R1/R2 を同じ倍率で下げて電流を増やす(比 R1 = 約 9 × R2 を保つ)、の順に試します。
- **出力を上げた場合は、微弱無線局の範囲を超えていないか、必ず測定で確認してください。**

### R1 と R2 を変えるときのルール
- 高低の比(約 10:1 = -20dB)を保つには **R1 = 約 9 × R2**(電流比は 1 + R1/R2)。
- 出力を変えるときは、R1 と R2 を**同じ倍率**で変えます。電流は並列抵抗(≒ R1/10)にほぼ反比例します。
- 例: 10k/1.1k(既定、約 2mA)、22k/2.4k(約 1mA)、68k/7.5k(約 0.3mA)。
- R2 は 330Ω 以上にします(74LVC125 の出力抵抗が約 25Ω あり、小さいと比が崩れます)。

## 時刻表示 LCD(J3)と送信信号 LED(D2)

### LCD(J3)
- 16×2 文字 LCD(I2C、3.3V、ST7032 系)。秋月電子の次の 2 点を想定(**LCD 本体と変換基板は別売り**)。
  - LCD 本体: AQM1602XA-RN-GBW(秋月通販コード 108779、680 円)。
  - ピッチ変換キット: AE-AQM1602A(KIT)(秋月通販コード 108896、780 円)。LCD 本体の細かいピッチの端子(9 本)を、変換基板にはんだ付けする。
  - 秋月の在庫は 2026-10-30 時点で「在庫あり」(確認済み。在庫は変動する)。
- J3 は 1×4 の**メスのピンソケット**で、基板の左下にある。変換基板の並び(**1 +V / 2 SCL / 3 SDA / 4 GND**)に合わせてある(基板上では上から GND / SDA / SCL / +V の順に並ぶ。向きを逆にして、I2C の配線が交差しないようにしている)。変換基板の 1×4 ピンヘッダ(キット付属かを確認)をはんだ付けして、J3 に挿す。ケーブルで離して置いてもよい。
- I2C のプルアップは Pi 側(1.8kΩ)を使うので、変換基板の**プルアップ用ジャンパはオープンのまま**にする。
- I2C アドレスは 0x3E(RTC の 0x68 と衝突しない)。
- 未確認: LCD 本体を J3 に挿したときの向き・張り出し(モジュールの寸法は 66×27.7mm)。J3 は基板の左下にあり、LCD は J3 から右へ約 66mm、下側の帯に載る想定(右端はコイルの近くまで来るので、LCD の金属部分がコイルに近づかないか実物で確認すること)。
- ソフト: `/etc/jjyd.toml` の `[lcd]`(`enabled`、`bus`、`address`、`contrast`)。1 行目に日付と曜日、2 行目に時刻・送信周波数・状態(`TX` = 送信中、`OFF` = 停止)を毎秒表示する。表示が薄い/濃いときは `contrast`(0〜63)を調整。LCD が無くても送信は続く。

### 送信信号 LED(D2)
- GPIO24 → R7(330Ω)→ D2(3mm 緑 LED)→ GND。
- 点灯のルール(低レベル期間だけ点灯): ビット 1 = 0.5 秒点灯 / ビット 0 = 0.2 秒点灯して消灯 / マーカー = 0.8 秒点灯。高レベルの間は消灯し、高レベルが終わると点灯、次の秒頭で消灯する。
- D1(赤、高レベルの間だけ点灯)と見比べると、パルスの形が分かる。
- ソフト: `/etc/jjyd.toml` の `[signal] gpio = 24`。

## RTC(基板上に実装)

DS3231SN(U2)と CR2032 ホルダ(BT1)を載せてあり、再起動直後でも NTP 同期を待たずに送信を再開できます。

- 配線: SDA = GPIO2、SCL = GPIO3、VCC = 3V3、VBAT = BT1 の +。I2C のプルアップは Pi 側(1.8kΩ)を使う。
- U2 は 32kHz / INT / RST を未接続にしている。C6 100nF が U2 のバイパス。
- BT1 は **手はんだ**。**極性(パッド 1 = +)を確認すること**(KiCad 標準フットプリントのシルクにも「+」がパッド 1 側に描かれているが、ホルダのデータシートでも確認する)。電池は 1 次電池(CR2032)。
- ソフト: `sudo ./scripts/install.sh` が `dtoverlay=i2c-rtc,ds3231` を有効化し、`/etc/jjyd.toml` の `[rtc] enabled = true` にする(既定)。前回同期から 24 時間以内なら、再起動直後に NTP 未同期でも送信を許可する。
- 未確認: Raspberry Pi 実機での RTC 動作(オーバーレイ・udev の手順は一般的な手順に沿ったもので、実機では未検証)。

## 調整手順

1. `sudo systemctl stop jjyd` のあと、実機で `sudo python3 -m jjyd` を起動する。
2. オシロで GPIO18 が 60kHz であること、GPIO23 が 1 秒周期で Low パルスになること(0.2 / 0.5 / 0.8 秒)を確認する。
3. 駆動ノード(R1/R2 とコイルの接続点)で、1 秒ごとに振幅が約 10:1 に変わることを確認する。
4. 電波時計をコイルの近くに置き、強制受信(多くは手動の受信ボタン)を試す。受信には約 2〜3 分(連続 2 フレームの確認)必要。
5. 受信できないときは、時計との距離・向き、`khz`(60 / 40)が時計の対応する局と合っているか、金属の近さを確認する。

## KiCad データ

[kicad/](kicad) に KiCad 8 以降で開けるプロジェクト(`jjy-hat.kicad_pro`)があります(ファイル名は旧称のまま)。
基板は 100×96mm、2 層。J1 は上辺の中央、部品は表面(SMD は U1・U2 のみ、他はリード部品)で、取り付け穴は四隅です。
プレビュー: [jjy-hat-pcb-preview.png](kicad/jjy-hat-pcb-preview.png)

- データは [kicad/gen_kicad.py](kicad/gen_kicad.py) で生成しています。部品値や配置、コイルの寸法(`COIL_*`)を変えるときは、このスクリプトを直して `python -I gen_kicad.py` で再生成します。
- フットプリント・シンボルは KiCad 標準ライブラリの実物を使い、自作の部品(74LVC125・DS3231SN・AQY212S の記号と、スパイラルコイルのフットプリント)はプロジェクト内のライブラリ([JJY.kicad_sym](kicad/JJY.kicad_sym)、[JJY.pretty/](kicad/JJY.pretty))にまとめています。
- コイルは銅箔の図形でできたフットプリントで、ネットタイ(DRV と GND のパッドを同じ導体でつなぐ宣言)にしています。
- KiCad 10.0.7 の ERC/DRC を実行して、**ERC 0 件・DRC 0 件(警告を含む)・未配線 0・回路図と基板の不一致 0**を確認済みです。
- 初回に開いたら、基板エディタで `B` キー(ゾーン再充填)を押して GND ベタを塗り直してください(コイルの範囲は銅ベタが入らない設定です)。
- 未確認: 実際の製造(基板メーカーのチェック)、コイルの実測(インダクタンス・電界強度)、実機動作。

## 履歴

- Rev A: 60kHz、Pi に挿す HAT 形、チップ部品、1mH のフェライトバー用の共振回路。
- Rev B: 40/60kHz 切替(フォトモスリレーで共振コンデンサを切替)、RTC、LCD、送信信号 LED。
- Rev C(現在): ケースの外に置く基板に変更(Pi とは GPIO のケーブルでつなぐ)、アンテナを基板上のスパイラルコイルに変更。共振回路と帯域切替(K1・C2〜C9)は廃止し、帯域はソフトのみで切替。外付けアンテナ用の J2 と、基板コイルとの選択ジャンパ JP1 を追加。外付け側の共振オプション(C2〜C9・K1・R6・JP2)は、未実装(DNP)で場所だけ用意。
