## 注文手順 (jlcpcb.com)

1. PCB を注文: `jjy-hat-gerber.zip` をアップロード。2 層 / 65×56mm / 1.6mm / HASL(鉛フリー可) / 数量は 5 枚〜。
2. 「PCB Assembly」を有効化 → 面: **Top** → 数量(5 枚なら 5)。
3. `jlcpcb/bom.csv` と `jlcpcb/cpl.csv` をアップロード。
4. **部品照合画面**で全 12 行にマッチし在庫があることを確認(下記)。
5. **部品配置プレビュー**で U1 と D1 の向きを確認し、ずれていれば回転をその画面で補正。

C5(微調整用、未実装)、BT1(電池ホルダ)と J1/J2(スルーホール)は組立対象外です。

- **BT1**: CR2032 ホルダ MYOUNG BS-07-A1BJ001(LCSC C2979167、スルーホール)+ CR2032 電池を別途用意して手はんだ。**極性(パッド 1 = +)をデータシートで確認**。
- **J1**: 2×20 の**スタッキングヘッダ**(Raspberry Pi 用の足長タイプ)を別途購入し、表面から挿して裏側ではんだ付け。
- **J2**: 1×2 の 2.54mm ピンヘッダ。アンテナのコイル(1mH 前後のフェライトバー)を接続。

## JLCPCB の DFM 警告への対応(Rev B 以降)

初回アップロード時に出た警告に合わせて、次の設定にしてある。

- ソルダーマスク拡張 0.05mm(開口をパッドより 0.05mm 広げる)。「Negative soldermask expansion」の警告対策。
- ビアはマスクで覆う(テンティング)。「Solder mask opening exposing trace」の警告対策。
- シルクの線幅は最小 0.16mm(標準フットプリントの 0.12mm を太くした)。「Silkscreen line width」の警告対策。
- 実装部品はすべて基板端から 3mm 以上(実装用の外枠が付く条件を避けるため)。

## 確認済み / 未確認

- 確認済み: 上記 LCSC 品番の型番・容量・耐圧・誘電体・パッケージ(LCSC の商品ページで確認)。
- **未確認**: 各品番の**現時点の在庫**と Basic/Extended の区別(データ源によって食い違い、確定できなかった)。
  C0G コンデンサ 3 種と U1 は Extended の可能性が高く、その場合は部品ごとに追加の段取り料がかかる。
  在庫切れの品番は、JLCPCB の部品照合画面で同容量・同誘電体(C0G, 50V, ±5%, 0603)の代替に差し替える。
- **未確認**: 部品の向き。U1(SOIC-14, 回転 0)、U2(SOIC-16W, 回転 180)、K1(SOP-4, 回転 180)と D1(LED, 回転 180)は、JLCPCB 側のライブラリの基準向きと異なる場合がある。
  プレビューでピン 1 と LED 極性を必ず確認する。
- 未確認: JLCPCB の CAM/DFM チェック。ガーバーはビューアでの目視確認も未実施。
- **未確認**: K1(AQY212SX)のピン配置(1=LED+, 2=LED−, 3/4=負荷)とフットプリント。データシートで確認すること。
- D1 を赤にしたのは、3.3V 駆動+1kΩ では Vf が約 3.3V の緑(C72043 など)は点灯しないため。
