再生成: `python -I ../export_fab.py`(設計 → ゾーン再充填 → ガーバー/ドリル/BOM/CPL を一括出力)

## 注文手順 (jlcpcb.com)

1. PCB を注文: `jjy-hat-gerber.zip` をアップロード。2 層 / **100×96mm** / 1.6mm / HASL(鉛フリー可) / 数量は 5 枚〜。
2. 「PCB Assembly」を有効化 → 面: **Top** → 数量(5 枚なら 5)。
3. `jlcpcb/bom.csv` と `jlcpcb/cpl.csv` をアップロード。
4. **部品照合画面**で U1・U2 の 2 行にマッチし在庫があることを確認(下記)。
5. **部品配置プレビュー**で U1・U2 の向き(ピン 1 の位置)を確認し、ずれていれば回転をその画面で補正。

## 手はんだする部品(別途購入)

JLCPCB では実装されません。

- **J1**: 2×20 ピンヘッダ(2.54mm、ストレート)。Pi とは 40 ピンのフラットケーブル(1 対 1)またはジャンパ線でつなぐ。
- **R1〜R5、R7、R8(リード、1/4W 金属皮膜 1%、縦置き)**: R1 = 10kΩ、R2 = 1.1kΩ、R3・R4 = 10kΩ、R5 = 1kΩ、R7 = 330Ω、R8 = 470Ω。**R1:R2 = 約 9:1 を保つこと**。
- **D1・D2・D3**: 3mm LED(D1 = 赤、D2 = 緑、D3 = 黄。D3 は通電表示)。足の間隔 2.54mm。四角いパッドがカソード。
- **C1・C6**: 100nF 50V の積層セラミック(リード、足の間隔 5.08mm)。
- **BT1**: CR2032 ホルダ MYOUNG BS-07-A1BJ001(LCSC C2979167、スルーホール)+ CR2032 電池。**極性(パッド 1 = +)をデータシートで確認**。
- **J3**: 1×4 のメスピンソケット(2.54mm)。LCD は秋月の AQM1602XA-RN-GBW(108779)+ ピッチ変換キット AE-AQM1602A(KIT)(108896)を別途購入し、LCD 本体を変換基板にはんだ付けして(端子が細かい)、1×4 ピンヘッダを付けて J3 に挿す。
- **JP1**: 1×3 ピンヘッダ(2.54mm)と短絡ピン(ジャンパ)1 個。アンテナ選択(1-2 = 外付け、2-3 = 基板コイル)。
- **J2**: 1×2 ピンヘッダ(2.54mm)。外付けアンテナ用。外付けアンテナのコイルは別途用意する(作り方は [hardware/README.md](../../README.md))。
- **共振オプション(通常は実装しない)**: JP2(1×2 ヘッダ + 短絡ピン)、C2〜C5・C7〜C9(C0G 50V)、K1(AQY212SX)、R6(330Ω)。部品表では DNP(未実装)で、JLCPCB の BOM にも含めていない。使うときは [hardware/README.md](../../README.md) の「共振オプション」を参照。
- **アンテナ**: 基板上のスパイラルコイル(L1)は部品が不要。

## JLCPCB の DFM 警告への対応

- ソルダーマスク拡張 0.05mm(開口をパッドより 0.05mm 広げる)。
- ビアはマスクで覆う(テンティング)。
- シルクの線幅は最小 0.16mm(標準フットプリントの 0.12mm を太くした)。
- 実装部品(U1・U2)は基板端から 3mm 以上。
- コイルの銅箔: 配線幅 0.25mm、間隔 0.35mm(JLCPCB の最小値の範囲内)。

## 確認済み / 未確認

- 確認済み: U1・U2 の LCSC 品番の型番・パッケージ(LCSC の商品ページで確認)。KiCad 10.0.7 の ERC/DRC(警告を含め 0 件)。
- **未確認**: 各品番の**現時点の在庫**と Basic/Extended の区別(データ源によって食い違い、確定できなかった)。U1・U2 は Extended の可能性があり、その場合は部品ごとに追加の段取り料がかかる。在庫切れの品番は、JLCPCB の部品照合画面で同等品に差し替える。
- **未確認**: 部品の向き。U1(SOIC-14, 回転 0)と U2(SOIC-16W, 回転 180)は、JLCPCB 側のライブラリの基準向きと異なる場合がある。プレビューでピン 1 を必ず確認する。
- 未確認: JLCPCB の CAM/DFM チェック。ガーバーはビューアでの目視確認も未実施。コイルの実測(インダクタンス・電界強度)も未実施。
- 基板サイズ 100×96mm は、JLCPCB の安価な区分(100×100mm 以内)に収まる想定。実際の見積もりで確認する。
